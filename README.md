# 🌌 MDK Chrono — 3D Age Calculator by Mr Sabir

An interactive, cinematic 3D scroll-driven temporal engine and exact age calculator built with **Three.js**, **Vite**, and **GPU-accelerated CSS3 3D Spatial Transforms**.

![Mr Sabir Logo](/logo.png)

## ✨ Key Features

- **Exact Chronological Precision**: Calculates your age down to years, months, days, hours, minutes, seconds, and live ticking milliseconds.
- **Cinematic 3D Scroll Journey**:
  - Rotating pearlescent MDK crystal monolith with warm golden orbits.
  - Interactive AI ChronoBot mascot with responsive LED eye canvas and cursor look-at tracking.
  - Floating parchment calendar leaves that flip through chronological time.
  - Brass mechanical timepiece with physical spinning gear trains.
  - Golden cosmic stardust particle field and dynamic studio lighting.
- **Physical 3D Spatial Emergence**: Cards rise smoothly from deep background 3D depth (`translateZ` and cubic ease curves) as you scroll.
- **Deep Biological & Cosmic Metrics**:
  - Estimated heartbeats lived.
  - Total breaths taken.
  - Cosmic solar orbit distance traveled aboard Earth (in billions of km).
  - Exact age on Mars.
- **Birthday Forecaster**: Countdown to next birthday + upcoming 5 birthdays day-of-the-week schedule.
- **Astrology & Zodiac**: Western zodiac signs with elemental traits and Chinese zodiac animal alignment.
- **Discord-Style Master Footer**: Complete with language selector, social media platforms, multi-column navigation, and giant **MR SABIR** typographic display watermark.

## 🛠️ Tech Stack

- **Three.js** (WebGL 3D Rendering)
- **Vite** (Next-Generation Frontend Tooling)
- **Vanilla JavaScript (ESM)** (Zero heavy framework overhead)
- **Canvas Confetti** (Celebratory particle physics)
- **Modern CSS3** (Frosted porcelain glassmorphism, perspective 3D transforms)

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Sabirusmani077/Age-calculator.git
   cd Age-calculator
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
